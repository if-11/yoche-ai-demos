# AI 影视制作 SOP 网站实施计划

1. 记录现有两个子页面基线哈希，准备共享静态资源目录。
2. 复制用户案例图片与 3 个 Skill Markdown 文件，统一为安全文件名。
3. 建立共享品牌样式和 Prompt 复制脚本。
4. 重构主页为纵向前期、中期、后期时间线，接入 13 个专题入口及状态。
5. 为现有两个页面仅添加顶部返回主页入口。
6. 创建前期新增专题页。
7. 创建中期人物、车辆、场景、分镜、去脏和视频专题页。
8. 创建 4 个可进入的后期草稿页，明确标注待完善。
9. 自动检查内部链接、图片、Skill 下载、页面标题、返回入口和复制控件。
10. 启动本地静态服务器，检查桌面与手机端真实页面。
11. 对比现有页面正文基线，确认没有非授权改动。
12. 提交并推送 GitHub，等待 Pages 发布完成后逐页验证线上地址。
